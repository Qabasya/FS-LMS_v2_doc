Мокапы интерфейсов FS-LMS 2.0

Кликабельные прототипы ключевых экранов. Спецификация — в 03-design.md, раздел 4.

Главная

Строка дня и счётчики-переходы, «Требует внимания» с конкретными задачами, расписание на день и неделю, ученики с провалами. Два вида: преподаватель и методист — переключатель ролей в шапке.

Преподаватель / методист · §3.1

Конструктор курса

Дерево разделов и уроков, полоса шагов с лимитом 20, отметки скопированного контента, редактор в стиле Дзена, автосохранение.

Методист · §4.1

Конструктор работы

Один конструктор на все виды: режим проведения (в плеере / с таймером / ЕГЭ) задаёт вендор и переключает настройки, тип работы — «тег» школы для журнала и отчётности.

Методист · §4.9

Банк задач

Список с фильтрами по предмету, проверке, сложности, номеру ЕГЭ и автору; у каждой задачи видно, где она используется. Массовые действия, импорт и экспорт.

Методист · §4.9

Конструктор задачи

Условие в редакторе §1.4, тип ответа списком (базовые и модульные), эталон под тип, критерии для ручной проверки, темы из справочника и блок «где используется».

Методист · §4.9

Экзамен

Прихожая с условиями, полноэкранный режим с липким таймером и панелью заданий, поведение при обрыве связи и при нуле на таймере, два вида результата.

Ученик · §4.6

Главная ученика

Приветствие, «Продолжить обучение» с последним шагом, расписание с кнопкой «Подключиться», список «Что сделать» со сроками и возвратами на доработку, свои результаты.

Ученик · §3.7

Плеер курса

Свёрнутое дерево, блокировка обязательным шагом, лонгрид с липким оглавлением, работа с панелью заданий. Три режима: ученик, предпросмотр, педагог.

Ученик · §4.2

КТП и расписание

Темы курса и календарь занятий, «Распределить», перетаскивание, перенос и отмена, доп. занятия, публикация со сводкой.

Методист · §4.3

Журнал

Сетка «ученики × занятия» с подколонками работ, ввод посещаемости с клавиатуры, баллы только для чтения, закреплённые итоги.

Преподаватель · §4.4

Проверка работ

Очередь по всем группам, карточка-страница с вкладками «Ответ / Эталон», оценивание по критериям, режим «подряд».

Преподаватель · §4.5

Урок по группе

Одна таблица: слева ученик, у него строка шагов урока и по строке на каждую работу — клетками её задания. Внизу — доля справившихся по каждой клетке.

Преподаватель · §4.12

Работа по группе

Ученики × задания работы, подсказка с ответом ученика и верным ответом, средний балл и статусы сдач. Разбор всей работы — в модуле ручной проверки.

Преподаватель · §4.13

Сводка по ученику

Карточка ученика с доступом в систему, шесть показателей всегда на виду и три вкладки: посещаемость с лентой занятий, работы, прогресс по шагам уроков.

Преподаватель · §4.11

Индивидуальные занятия · Расписание

Недельная сетка по рабочему времени, планирование у методиста и просмотр у преподавателя — переключатель ролей в шапке.

Методист / преподаватель · §4.10
Как читать мокапы
  • Открывать в обычном браузере — во встроенных панелях предпросмотра JS не выполняется.
  • Демо-переключатели (роль, режим) подписаны словом «демо» — в продукте их нет: вид определяется правами.
  • Данные вымышленные; действия показывают тосты вместо реальных запросов.
  • Общий каркас и переменные — в _shared.css: высота шапки, карточка пользователя, палитра, кнопки, оверлеи.
  • Иконки и цвета типов шагов — в _icons.js (stepIcon, stepName, stepColor): один набор на конструктор, плеер, сводку по ученику и урок.
